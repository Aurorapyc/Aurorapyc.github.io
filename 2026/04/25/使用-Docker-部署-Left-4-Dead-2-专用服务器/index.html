使用 Docker 部署 Left 4 Dead 2 专用服务器（含 SourceMod 与调优）

发表于2026-04-25|更新于2026-10-07|运维实践

用 Docker 把 L4D2 服务端跑起来，从装 SteamCMD 到插件、管理员、Tickrate 全部走一遍，最后得到一台能联机、支持 SourceMod 的专用服务器。

1. 使用场景与目标读者

  • 你有一台 Linux 服务器（Ubuntu 22.04 推荐）
  • 你想用 Docker 隔离环境，避免污染宿主机
  • 你需要支持 SourceMod/MetaMod 插件的完整 L4D2 服务端
  • 你熟悉基础命令行操作，但不熟悉 SteamCMD 或 L4D2 服务端细节

2. 先决条件

  • 已安装 Docker Engine 和 Docker Compose（v2+）
  • 宿主机开放 UDP/TCP 27015 端口
  • 一个有效的 Steam 账号（2024 年后匿名账号无法下载 L4D2 服务端）

3. 部署流程概览

  1. 准备项目目录与脚本
  2. 启动容器并自动安装游戏服务端
  3. 验证服务是否运行成功
  4. 安装 SourceMod / MetaMod 插件
  5. 配置管理员、游戏模式与 Tickrate

注意：不建议一次性执行全部步骤。每完成一步，请验证后再继续。

6. 常见问题

问题 原因 解决方案
ERROR! Failed to install app '222860' 匿名账号被 Steam 限制 使用个人账号登录
插件未加载 metaplugins.ini 缺失条目 检查并添加 sourcemod_mm
100 Tick 无效 客户端未配置 cl_cmdrate 在 autoexec.cfg 中设置
容器启动后退出 install.sh 报错，或 start.sh 非前台进程 用 docker compose logs 查看错误

7. 维护与更新

  • 更新游戏：进入容器，重新运行 install.sh（确保账号凭据有效）
  • 备份配置：只需备份 ~/l4d2/server-files 目录
  • 升级插件：替换 addons/ 下对应文件即可
